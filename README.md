# 考研备考助手 408exam

覆盖 **408 / 数学二 / 英语二 / 政治** 四个科目，每科均含「真题库 + 练习题题库」，并提供随机练习、模拟考试、错题本（艾宾浩斯遗忘曲线智能复习）、知识点与闪卡背诵、学习统计、每日计划与打卡、番茄钟、成就系统、全库备份等功能。

数据保存在浏览器 **IndexedDB**（本地，不上传服务器），支持 JSON/CSV/Excel 导入导出与全库备份恢复。

## 技术栈
- React 19 + TypeScript + Vite 7
- ECharts 5（统计图表）
- SheetJS xlsx（Excel 导入导出）
- IndexedDB（零依赖手写封装，大数据量不卡顿）
- Node 内置 test runner + tsx（核心算法单测）

## 运行
```bash
npm install
npm run dev       # 本地开发
npm run build     # 类型检查 + 生产构建（输出 dist/）
npm run preview   # 预览生产构建
npm test          # 运行核心算法单元测试
```

## 题目导入格式
首行字段名（JSON 为对象数组，或 `{ "questions": [...] }`）：
```
id, subject, bank, year, type, chapter, source, question, options, answer, analysis, kpIds, tags, difficulty, done, correctCount, wrongCount, note
```
- `subject`：`408` / `math2` / `english2` / `politics`，缺省时归入当前所选科目
- `bank`：`real`（真题，默认）/ `practice`（练习题）
- `type`：`single` 单选 / `multi` 多选 / `judge` 判断 / `fill` 填空 / `essay` 解答
- `options`：JSON 数组字符串 `["甲","乙"]`，或用 `|` 分隔的文本
- `answer`：单选 `A`；多选 `AC`（顺序无关）；判断 `T/F`（也接受 对/错、√/×）；填空/解答为参考答案，做题时自评
- `tags`、`kpIds`：多个值用 `|` 或逗号分隔
- `difficulty`：1 简单 / 2 中等 / 3 困难
- 相同 `id` 执行更新而非重复新增；旧 408 数据缺少新字段时自动补默认值
